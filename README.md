# Dual-Axis-Solar-Tracker-Voltage-Monitoring
Developed a dual axis solar tracker system that automatically aligns the solar panel with the sun in both horizontal and vertical directions to maximize energy generation. The project includes an automatic dust cleaning mechanism that activates when dust is detected, improving panel efficiency and reliability. Real-time voltage monitoring is implemented to observe solar panel output and system performance. The system uses LDR sensors for sun tracking, a microcontroller for control and monitoring, motor driver circuits for panel movement, servo/DC motors for actuation, voltage sensing circuits, and embedded programming for automation and data processing.
